EtchDroid ایک اوپن سورس ایپ ہے جو USB ڈرائیوز پر امیج لکھنے میں آپ کی مدد کرتی ہے۔
جب آپ کا لیپ ٹاپ کام نہ کر رہا ہو تو اسے استعمال کرکے آپ ایک Bootable آپریٹنگ سسٹم USB ڈرائیو بنا سکتے ہیں۔


⭐ معاون ڈیوائسز ⭐


✅ USB فلیش ڈرائیوز

✅ USB SD کارڈ اڈاپٹرز

✅ USB ہارڈ ڈرائیوز / SSDs

❌ USB ڈاکس اور ہبز

❌ بیرونی SD کارڈ سلاٹس

❌ آپٹیکل یا فلاپی ڈسک ڈرائیوز

❌ صرف Thunderbolt کے لیے بنائی گئی ڈیوائسز


⭐ معاون ڈسک امیج کی اقسام ⭐


✅ جدید GNU/Linux آپریٹنگ سسٹمز کی امیجز، جن میں Arch Linux، Ubuntu، Debian، Fedora، Pop!_OS، Linux Mint، FreeBSD، BlissOS اور بہت سے دوسرے شامل ہیں۔

✅ Raspberry Pi کی SD کارڈ امیجز (لیکن پہلے انہیں Unzip کرنا ضروری ہے)۔

❌ Microsoft Windows کی آفیشل ISOs

⚠️ کمیونٹی کی تیار کردہ Windows امیجز جو EtchDroid کے لیے بنائی گئی ہیں (احتیاط کریں: ان میں وائرس ہو سکتے ہیں!)

❌ Apple کی DMG ڈسک امیجز

❌ 2010 سے پہلے کی پرانی GNU/Linux OS امیجز، مثلاً Damn Small Linux۔
